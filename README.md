# Simulation Academy — OOP Assignment 1

This repository contains my solution for the Simulation Academy .NET OOP Assignment.

The assignment focuses on Object-Oriented Programming, Design, Encapsulation, Builder Pattern, and algorithmic problem solving.

## Assignment Parts

### Part 1 — Procedural to OOP

Analyze an existing procedural implementation and refactor its design toward Object-Oriented Programming principles. The task focuses on identifying design problems, improving encapsulation, and assigning responsibilities to appropriate classes.

### Part 2 — Hotel Reservation System

Design and implement a hotel reservation system using Object-Oriented Programming principles. The task focuses on classes, relationships, encapsulation, responsibilities, and applying appropriate validation and business rules.

### Part 3 — Builder Pattern

Analyze the problems of constructing an object with a large number of parameters and redesign its construction using the Builder Pattern. The solution also uses smaller, composed builders such as `AddressBuilder` and `OrderBuilder` to improve separation of responsibilities, validation, reuse, and readability.

### Part 4 — LeetCode — Two Pointers

Solve LeetCode Problem 1679, **Max Number of K-Sum Pairs**, using the Two Pointers technique. The solution sorts the array first and then uses two pointers moving from both ends to find pairs whose sum equals `k`. An Accepted submission screenshot is included as proof of the solution.
